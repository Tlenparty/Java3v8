# Java Concurrency Samples

Небольшие примеры на Java 8: многопоточность, unit-тесты на JUnit 5
и собственный мини-фреймворк тестирования на аннотациях и рефлексии.

## Содержание

| Пакет | Что делает |
|-------|------------|
| `waitnotify` | Три потока по очереди печатают буквы `A`, `B`, `C` (ABCABC…), синхронизация через `wait` / `notify`. Известное ограничение: на последнем круге потоки зависают в `wait()` |
| `race` | Симуляция гонки: машины стартуют одновременно (`CountDownLatch`, `CyclicBarrier`), в тоннель пускаются не более двух (`Semaphore`), объявляется победитель и окончание гонки |
| `arrays` | `ArrayUtils`: элементы после последней четвёрки в массиве и проверка, что массив состоит только из 1 и 4; покрыто тестами JUnit 5 |
| `testframework` | Аннотации `@BeforeSuite`, `@Test(priority)`, `@AfterSuite` и запускатель `AbleToDoTest`, который через рефлексию выполняет методы в порядке приоритета |

## Стек

| Область | Технологии |
|---------|------------|
| Язык | Java 8 |
| Сборка | Maven |
| Тесты | JUnit 5 |

## Сборка и запуск

```bash
mvn package
java -cp target/classes race.Main
java -cp target/classes testframework.AbleToDoTest
```
